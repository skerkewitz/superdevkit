> This is still an alpha release. It works for me, that doesn't necessarily mean it works for you at the moment. Sorry 😔.

superdevkit is a development kit for SNES games written in C. You write a game once, and it builds as a ROM for the Super Nintendo, a program for Linux and Windows, and a page for the browser. It comes with dampf, its own C compiler for the SNES's 65816 CPU.

**[Play the example games in your browser](https://skerkewitz.github.io/superdevkit/example/)** · **[Read the book](https://skerkewitz.github.io/superdevkit/book/)**

## Download

| Your system | File |
| --- | --- |
| Windows (x64) | `superdevkit-0.9.2-windows-x64.zip` |
| Linux or WSL (x64) | `superdevkit-0.9.2-linux-x64.zip` |

Each zip brings its own Java, so you don't need to install one.

## Your first ROM

On Windows, in PowerShell, in the folder with the zip:

```powershell
Expand-Archive superdevkit-0.9.2-windows-x64.zip .
$env:Path = "$PWD\superdevkit-0.9.2\bin;$env:Path"
superdevkit init mygame
cd mygame
superdevkit build snes
```

On Linux or WSL:

```sh
unzip superdevkit-0.9.2-linux-x64.zip
export PATH="$PWD/superdevkit-0.9.2/bin:$PATH"
superdevkit init mygame
cd mygame
superdevkit build snes
```

The ROM is `build/snes/mygame.sfc`. [Getting started](https://skerkewitz.github.io/superdevkit/book/guide/getting-started) goes on from there.

## What each target needs

| Target | Command | You need |
| --- | --- | --- |
| SNES | `superdevkit build snes` | nothing else (an emulator such as MesenCE to play the ROM) |
| Windows | `superdevkit build win64` | Visual Studio with "Desktop development with C++" |
| Linux | `superdevkit build linux` | a C compiler and the OpenGL and X11 development libraries |
| Web | `superdevkit build web` | the Emscripten SDK, with `emcc` on the PATH |

## New in 0.9.2

A small maintenance release: the website is set up for Google Search, so the book and the games can be found there. The kit works as it did in 0.9.1, and dampf and the code it generates are unchanged since 0.9.0.

## Known limits

- Music plays on the desktop and the web, but not yet on the SNES. Sound effects and save RAM work there.
- The kit has been tested in emulators, not on a real SNES.
- The C subset, the command line and the files dampf writes may change before 1.0.
- The games on the website need a keyboard.
